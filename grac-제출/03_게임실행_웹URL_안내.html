1. 심사용 게임 실행 주소

제출한 게임 파일은 웹 게임의 구성 파일(HTML·JavaScript)이라 파일만으로는 실행이 번거로울 수 있습니다. 아래 주소를 웹브라우저 주소창에 입력하시면 설치·로그인·회원가입 없이 즉시 게임이 실행됩니다.

권장 기기스마트폰(안드로이드 Chrome / iOS Safari). 세로 화면 전용으로 설계된 게임입니다
PC에서 볼 때PC 브라우저에서도 마우스 왼쪽 버튼 클릭으로 동일하게 플레이할 수 있습니다. 다만 화면이 가로로 넓게 늘어나므로, 실제 화면과 같이 보시려면 아래 2항의 방법을 이용해 주십시오

2. PC에서 실제 화면 그대로 확인하는 방법

  1. Chrome 또는 Edge 브라우저로 위 주소를 엽니다.
  2. 키보드 F12를 눌러 개발자도구를 엽니다.
  3. 개발자도구 왼쪽 위의 휴대기기 모양 아이콘을 클릭합니다 (단축키 Ctrl + Shift + M).
  4. 화면 위쪽 기기 목록에서 iPhone 14 Pro 등 아무 스마트폰이나 선택하거나, 직접 크기를 가로 393 × 세로 749로 입력합니다.
  5. F5로 새로고침하면 실제 스마트폰과 동일한 화면이 나타납니다.
개발자도구를 열지 않고 간단히 확인하시려면, 브라우저 창의 가로 폭을 좁게 (400px 내외) 줄이기만 해도 세로 화면 배치로 바뀝니다.

3. 조작 방법 (요약)

  • 시작 화면에서 화면을 탭(클릭)하면 게임이 시작됩니다.
  • 화면 위쪽에서 블록이 좌우로 왕복합니다. 화면 아무 곳이나 탭하면 그 위치에서 블록이 아래로 떨어져 아래 블록 위에 얹힙니다.
  • 아래 블록과 겹치지 않은 부분은 잘려 떨어져 나가며 블록 폭이 그만큼 줄어듭니다. 어긋남이 아주 작으면 「딱!」으로 판정되어 잘리지 않고, 세 번 연속 성공하면 폭이 조금 회복됩니다.
  • 블록이 아래 블록을 빗나가거나 남는 폭이 너무 좁아지면 게임이 끝납니다. 결과 화면의 [다시 하기]를 탭하면 새로 시작합니다.
  • 쌓아 올린 층수가 점수입니다. 높이 올라갈수록 블록이 빨라지고 배경 하늘이 낮 → 노을 → 밤 → 우주로 바뀝니다.
같은 날에는 모두가 같은 탑을 쌓습니다. 블록의 속도 변화와 첫 출발 방향이 그날의 날짜로 정해지기 때문입니다. 심사 중 여러 번 플레이하셔도 같은 날 안에서는 같은 조건이 반복됩니다. 날짜가 바뀌면 새로운 탑이 열립니다.

4. 게시한 내용

위 주소에는 등급분류 신청 시 제출한 게임 파일 높이높이_게임빌드.zip과 완전히 동일한 빌드 산출물을 그대로 게시했습니다. 파일이 바이트 단위로 일치하며, 그 근거(SHA-256 해시값)는 별도 문서 「게임물 용량 확인자료」에 기재했습니다.
