### 다시 찍는 방법 — 크롬 MCP (헤드리스 촬영기는 이번에 못 썼다)

`tools/grac-shots.mjs`(헤드리스 크롬 + CDP)는 이번 세션에서 **페이지에 `window.__nopi` 훅이 붙기 전에
스크립트가 붙어 실패**했다(vite 8 + 헤드리스 조합). 제출본 8장은 **크롬 MCP로** 찍었고 절차는 이렇다:

1. `npx vite --port 5178 --strictPort --host 127.0.0.1` 로 개발 서버를 띄운다
2. 크롬 MCP로 `http://127.0.0.1:5178/tools/frame.html` 을 연다 (393×749 iframe 하네스)
3. 상단 프레임에서 iframe을 좌상단에 고정한다 — `position:fixed;left:0;top:0;width:393px;height:749px`
   (frame.html의 기본 배치는 가운데 정렬이라 iframe이 390×744로 어긋난다)
4. 장면 조작은 iframe의 `contentWindow.__nopi`(DEV 훅)로 한다. `build(n, offsets)`·`miss()` 도우미를 상단 프레임에 심는다
5. **함정 셋** — 배경 탭은 브라우저가 rAF와 타이머를 조인다:
   - `contentWindow.requestAnimationFrame = () => 0` 으로 페이지 프레임 루프를 끄고 `__nopi.stepOnce(dt)`로만 그린다.
     끄기 직전에 예약된 콜백 하나가 뒤늦게 한 번 더 그리므로, **끈 뒤 1초쯤 기다린 다음** 장면을 만든다
   - 팝업(「딱!」·「폭 회복!」)은 수명이 900ms다. 여러 층을 한 번에 쌓으면 팝업이 겹쳐 쌓이므로,
     깨끗한 장면은 **1.2초 흘려보낸 뒤 한 프레임 그리고** 찍는다
   - 사망 카드는 첫 dead 프레임부터 1.9초가 지나야 다 나온다. **호출을 두 번으로 나눠** (miss+그리기 → 다음 호출에서 그리기) 찍는다
     (배경 탭에서 `await sleep()` 루프를 길게 돌리면 CDP가 45초에 끊긴다)
6. 캡처는 `computer` 도구의 `zoom` + `region: [0,0,393,749]`, `save_to_disk: true`

## 접수 절차

동결 전 코드 쪽 항목은 끝났다: 실기기 판정으로 밸런스 확정 · 상단 칩 여백 수정(B4) · 개발 훅 배포본 0건 확인 ·
동결 빌드로 zip·해시·스크린샷·PDF 생성.

1. **[사용자] 심의용 웹 주소 게시 여부 결정** — 리포 public 전환 또는 별도 public 리포. 게시 뒤 SHA-256 대조.
   (게시하지 않으면 01·02·03 문서의 주소 관련 기재를 들어내야 한다)
2. **[사용자] GRAC 등급분류 검색으로 「높이높이」 동명 재확인** (슈팅스타 1차 보완의 원인).
3. **[사용자] 플레이 영상 촬영** → `04_게임플레이영상_높이높이.mp4` (git에는 넣지 않는다). **B4 빌드**로 찍는다.
   시작 → 초반 쌓기 → 딱 3연속·폭 회복 → 노을·밤 → 빗나가 사망 → 결과 카드(이어하기 버튼)까지 한 판이면 된다.
4. **[사용자] 사업자등록증 · 게임물제작업자등록증** — 앞선 제출본과 동일 (토니소프트). 상호가 사업자등록증·콘솔
   등록자명과 **글자 그대로** 같은지 대조 (한줄팡의 `토시소프트` 오기 사고).
5. **[사용자] GRAC 접수 + 수수료 결제** — 신청서 「게임물 개요」란에 `00_게임물개요_1000자.txt`, 첨부에 01·02·03 PDF +
   04 영상 + `높이높이_게임빌드.zip`. 모의계산 https://www.grac.or.kr/SupplementaryService/SimulatedCaculation.aspx
6. **접수 후에는 게임 내용을 바꾸지 않는다.** UI·버그 수정은 무방(플레이북 §4). 배너 광고와 순위·공유·종료 확인 창은
   설명서 10항·14항에 미리 적어 두었다 — 넣게 되면 01 문서 6항·14항, 03 문서 6항을 고친다(내용 변경은 아니다).
7. 등급분류 결정이 나면 콘솔 앱 정보에 증명서·등급분류번호·이용등급을 넣는다. 게임 화면에 등급 마크를 그릴 필요는 없다.
