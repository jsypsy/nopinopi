## D-001. 장르: 원버튼 탑 쌓기 + 일일 시드. 설계 1순위는 리워드 광고 수익 (2026-09-04)

- 배경: 한줄팡(14일)·슈팅스타(4일) 콘솔 지표 비교(2026-09-04). 짧은 판·즉사·이어하기 구조가 퍼즐보다
  사용자당 판수 2배(8.5 vs 4.1), 광고 전환 1.5배(22% vs 15%), D1 3배(14% vs 5%). 그러나 둘 다 유입이 플랫폼
  노출(미니앱홈·전체탭)뿐이라 첫 주 뒤 DAU가 1~5로 떨어진다 — **돌아올 이유가 없다.** 세 앱 전부 판마다 리셋
- 후보 셋(탑 쌓기 / 일일 도전형 원버튼 / 낙하 회피) 중 사용자 결정: **탑 쌓기에 일일 시드를 얹는다.**
  새 코어로 장르를 넓히면서 리텐션 가설 하나를 검증한다. 슈팅스타 유입이 남성 79%로 쏠린 점도 고려 — 성별 중립 소재
- 규칙: 좌우 왕복 블록을 탭으로 낙하 → 겹친 폭만 남김 → 빗나가면 즉사. 딱(±7px)이면 안 잘리고 3콤보마다 +14px 회복.
  점수 = 층수. 속도는 40층까지 램프 후 상한. 스틱 히어로류와 달리 한 작품이 소유한 메커니즘이 아닌 공용 장르
- **일일 시드**: KST 날짜 → FNV 해시 → 층마다 속도 변주(0.85~1.2)·첫 출발 방향. 오늘 최고·연속 일수를 로컬에.
  리더보드는 역대 최고(플랫폼). 일일 리더보드는 플랫폼이 지원하는지 Phase 2에서 확인 — 안 되면 "오늘 최고"는 로컬만
- 수익 역산 원칙 5(날아날아 D-001 승계): 누적 점수 · 즉사 · 내 탓인 죽음 · 30~60초 세션 · 이어하기 판당 2회(폭 60% 복원)
- 소리 없음(날아날아 D-022 승계). 그래픽은 코드로 그리는 도형. 에셋 0

## D-003. 소리 넣는다 — 날아날아 D-022(소리 없음)를 이 앱에서는 승계하지 않음 (2026-09-04)

- B1 실기기 플레이 뒤 사용자 판단: "얘는 사운드 넣어도 되겠다, 단순해서." 날아날아는 연출이 많아 소리가 소음이 됐지만,
  높이높이는 사건이 탭·딱·빗나감 셋뿐이라 소리가 곧 피드백이다(딱 판정 ±7px을 귀로 확인)
- 구현: `src/audio.ts` WebAudio 합성 3종 — 탭 낙하 '톡'(삼각파 320→140Hz, 80ms) · 딱 '띵'(사인 880Hz, 콤보마다 반음 상승, 12콤보에 한 옥타브) ·
  빗나감 '쿵'(톱니파 160→40Hz + 저역 노이즈). **에셋 0 유지**. AudioContext는 첫 포인터다운에서 생성·resume(iOS 정책)
- ~~토글: 타이틀 화면 「소리 켜짐/꺼짐」 알약~~ → **B3에서 제거.** B2 실기기: 기기에서 소리를 끄고 켜도 알약이 따라오지 않는다.
  웹뷰는 무음 스위치·볼륨 상태를 읽을 수 없어 앱 안 표시가 실제와 어긋난다 — 사용자 "즉각 반영이 어려우면 그 UI는 빼는 게 맞다".
  소리는 항상 켜 두고 볼륨은 기기에 맡긴다. `nopi.v1.muted` 키도 지움
- 계측 항목은 아직 없음 — 뮤트 비율이 궁금해지면 `nopi_mute` 추가

## D-004. 최고 기록 저장은 단조 증가 — 세션 내 옛 값과 비교하던 버그 수정 (2026-09-04)

- B1 실기기 보고 "오늘 최고가 갱신이 안 된다". 원인: 사망 시 `n > dailyBest`로 저장 여부를 정하는데 메모리 값은 `phase === 'ready'`
  프레임에서만 다시 읽었고, 「다시 하기」는 `newGame()` 직후 `startRun()`으로 ready 프레임 없이 playing이 된다 → 두 번째 판부터
  첫 판 이전 값과 비교해 **더 낮은 층수로 덮어썼다**(역대 최고도 같은 경로)
- 수정 두 겹: `newGame()`에서 저장값을 다시 읽고, `saveBest`/`saveDailyBest`는 기존 값과 max로 쓴다(저장 층에서 회귀 차단)
