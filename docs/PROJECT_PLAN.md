# 높이높이 — 프로젝트 계획

## 한 문단 요약

원버튼 탑 쌓기 하이스코어 게임. 블록이 좌우로 왕복하고, 탭하면 떨어져 아래 블록 위에 얹힌다.
어긋난 만큼 잘려 폭이 줄고, 빗나가면 즉사. 딱 맞추면 잘리지 않고 콤보, 3연속이면 폭이 조금 회복된다.
점수는 층수. **일일 시드**로 같은 날엔 모두가 같은 탑(속도 변주·출발 방향)을 쌓고, "오늘 최고"·"연속 N일"이
돌아올 이유가 된다. 게임오버 시 리워드 광고로 이어하기(판당 2회, 폭 60% 복원).

## 핵심 루프

```
탭        이동 블록 낙하 → 겹친 폭만 남는다 (딱이면 그대로)
즉사      겹침 없음 / minW 미만
점수      층수. 오늘 최고(로컬) · 역대 최고(로컬 + 리더보드)
하루      KST 자정에 새 탑. 연속 플레이 일수(streak)
```

**프로토타입에서 답할 질문**
1. 속도 램프(`speed`)와 딱 판정(`perfectTol`)의 조합에서 평균 세션이 30~60초인가 — 봇 분포로
2. 폭 회복(3콤보 +14px)이 "만회"로 느껴지는가, 아니면 무한 생존을 만드는가
3. 일일 시드가 "오늘 탑이 다르다"고 **느껴지는가** (속도 변주 ±만으로 부족하면 바람·리듬 변주 추가)
4. 카메라·잘린 조각 낙하·배경 고도 변화가 "높이 올라간다"를 파는가

## 단계

- **Phase 0 — 프로토타입** (지금): core + 카툰 렌더 + mock 어댑터. 위 질문 4개
- **Phase 1 — 완성**: 이어하기 루프 · 오늘 최고/역대/연속 일수 · 튜토리얼(데모 카드) · 계측 · 리더보드(플레이 완료 후, 인메모리 점수만)
- **Phase 2 — 플랫폼**: 콘솔 등록 · 테스트 배포 · 광고 지면 · 공유
- **Phase 3 — 심사·출시**: 제명 재검색 → GRAC(날아날아 구성 복제) → 콘솔 검수 → 출시. 핵심 지표(전환 「리워드 광고 시청 완료」·「몰입 플레이」)

## 수익 구조

- 이어하기 리워드 광고 — 주력. 판당 2회. 지면은 출시 직전 발급(23일 무노출 삭제)
- 배너는 상단·하단만 — Phase 2에서 판단

## 성공 기준

- Phase 0: "내일도 오늘의 탑을 다시 쌓고 싶은가" (사용자 실플레이)
- 출시 후: D1 리텐션이 슈팅스타(14%)를 넘는가 — 일일 시드 가설의 판정 숫자
